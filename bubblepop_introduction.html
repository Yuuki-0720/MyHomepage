ゲーム概要

基本体験

プレイヤーはクラリィを操作し、頭の判定エリアでシャボン玉を弾いてスコアや距離を伸ばします。 操作はシンプルですが、ヒット音、破裂音、端末振動、Bubbleのぷにょ変形、海中演出により「触って気持ちいい」反応を重ねています。

  • 頭の中心に近いほど高得点・高精度。
  • Normal / Time Attack / Center Hit の3モード。
  • 落下・時間切れ・規定ヒットでリザルトへ遷移。

作業用体験

Clock Mode / Pomodoro / Timer は、海中の美しさとクラリィのかわいい動きを活かした「眺めるゲーム」機能です。 Ver1.4ではプリセット式だった海時間を連続スライダーへ更新し、勉強・作業・休憩の背景として好みの光を細かく選べるようになりました。

  • タイトルは実時刻・季節に連動する海を表示可能。
  • 設定/ポーズから4:30〜24:00を15分刻みで選択。
  • クラゲコンパニオンは癒やしに加え、1プレイ最大2回まで落下を救助。
  • ゲーム中の髪が移動・停止・旋回へ控えめに遅れて、ふわっと揺れる。

ゲームモード

Normal Endless

Bubbleを落とすまで続く基本モード。距離、ヒット回数、命中率、スコアを伸ばす。海時間の既定は 日中。

  • スコア、総移動距離、最大/平均精度を記録。
  • 同じ位置での放置連続ヒットはコンボガードで抑制。
  • 落下/破裂でリザルトへ移行。

Time Attack

60秒でどれだけ距離とスコアを伸ばせるかを競う短時間モード。海時間の既定は 夜。

  • 時間切れまたは落下で終了。
  • テンポ重視。ランキング/シェアとの相性が高い。
  • ポーズ画面から海の光をカスタム時刻へ即時変更可能。

Center Hit

15回のヘディングで中心精度を競う採点モード。海時間の既定は 夕焼け。

  • 中心ほど高得点。端でも最低命中率を保証。
  • 連続高精度でコンボ倍率が上昇。
  • Bubbleの水平移動はランダム方向で、中心狙いを成立させる。

Bubble 挙動 / 当たり判定 / Shader 詳解

Bubble は HeadingBall の物理、BubbleEffect のヒット変形、 BubbleShader の透明膜、BubbleBurst の破裂演出で構成されます。 Ver1.4でも中核ロジックは維持されています。

通常モードの跳ね返り

  1. Bubble が HeadingZone に衝突する。
  2. 頭ローカル座標へ変換し、中心からの offset を求める。
  3. centerThreshold 内は真上、外側は衝突方向へ Slerp して角度を付ける。
  4. targetHeightY と滞空倍率から垂直初速・カスタム重力を計算。
  5. 水平速度を更新し、Bubble の linearVelocity へ反映。

放置コンボ防止

Normal / TimeAttack では、前回とほぼ同じ頭ローカル位置で連続ヒットした場合に comboGuardDistance と comboGuardMaxRepeats で放置判定します。 閾値を超えると命中率を0にし、ランダム水平ナッジでループを崩します。

Center Hit は毎回ランダム方向へ飛ばすため、同じ位置での放置ループが成立しにくい設計です。

透明膜とFresnel

BaseColor、Alpha、Fresnel を組み合わせ、外縁ほど光る薄膜感を作ります。 命中方向の色は MaterialPropertyBlock 経由で個体へ反映し、共有Materialを汚さない設計です。

Directional Lightはどう傾くか

カスタム時刻では、Profileの色補間とは別に太陽高度を計算し、主光源の X回転だけ を更新します。 Quaternion.Euler(sunPitch, 0, 0) なので、朝から昼は光が上から差す方向へ深く傾き、午後は逆順で浅くなります。 Y（方位）とZ（ロール）は常に0で、東から西へ横切る方位回転は行いません。

太陽高度からX回転を求める

緯度は伊予市/松山相当の φ = 33.76°。季節モデルの日の出・日の入りから赤緯δを逆算し、選択時刻の太陽高度eを求めます。

solarNoon = (sunrise + sunset) / 2 H0 = ((sunset - sunrise) / 2) × 15° δ = atan(-cos(H0) / tan(φ)) H = (hour - solarNoon) × 15° e = asin(sinφ sinδ + cosφ cosδ cosH) dayPitch = max(e, 28°) weight = InverseLerp(-2°, 6°, e) sunPitch = Lerp(authoredPitch, dayPitch, weight)

赤緯を独立した天文データから持たず、既存の季節別日長と整合するよう日の出時の高度0°から逆算します。

28°の下限

太陽が低い朝夕に光を水平近くまで倒すと影が極端に長くなるため、日中として扱う区間はX回転を28°以上に保ちます。10:30〜14:00付近は実際の太陽高度をそのまま使います。

地平線付近はProfileへ戻す

太陽高度が-2°以下ならプリセット角度、-2〜6°はプリセットから計算角へ滑らかに移行します。Dawn / Sunset / Nightの作り込んだ見え方を壊さず昼の連続変化だけを足します。

非カスタム時: Titleの現実時刻、および各ゲームモードのデフォルトでは solarHour < 0 のため、この実高度補正は行わずProfileの光源角度を使用します。 実高度による連続X回転は、ユーザーが「カスタム」を選んだときだけ有効です。

Ver1.4 クラゲコンパニオン救助

クラゲは普段クラリィの周囲を静かに漂い、クラリィが走っても確実に届かない落下だけを引き受けます。 助けると決めたら縦に伸びて消え、バブルの下へ現れて真上へ弾き、役目を終えた1匹は上方へ去ります。

登場と回数制限

時間スケジュール15, 45, 180, 600秒。タイトルでは15秒で1匹、45秒で2匹、3分で3匹、10分で4匹。
Normal距離20, 55, 120, 260m。"Bubble"タグの移動距離で順に増える。
救助上限1プレイ maxRescuesPerPlay = 2 回。無限救済を防ぐ。
補充待ち救助した1匹が去ってから rescueReturnDelay = 20 秒後に補充可能。

発動条件

残り時間低い迎撃点まで概ね 1.2秒以内になってから判定。
届かない判定反応時間0.22秒と走行可能距離を見積もり、さらに0.7m以上不足する場合だけ。
画面内rescueRequireOnScreen が既定ON。見えない場所で勝手に救わない。
迎撃高さ足元から0.85m。バブル半径0.635mを考慮した地面すれすれの高さ。

プレイを横取りしない

  • 落下地点を追い回すエスコート機能は実装を残しつつ既定OFF。
  • クラリィの反応時間・現在速度・最高速度から「まだ間に合う」場面は見送る。
  • 救助後は水平速度を0にして真上へ弾き、次の一球を自分で追える時間を作る。
  • RescueBounce() も通常の OnHeading を通るため、スコア・SE・振動・難易度更新は共通。

演出と成立保証

  • 泳いで横断せず、WarpOut → WarpIn の伸縮と粒子で救助地点へ移動。
  • 残り時間が短い場合はワープ時間を比率維持のまま短縮。
  • 一度引き受けた救助は、落下寸前なら迎撃点へ寄せて成立を優先。
  • 成立位置へUI Toolkitの吹き出しを約2秒表示し、何が起きたかを明示。

自動セットアップ

  • RuntimeInitializeOnLoadMethod と Manager の二重保証で、PlayerController を持つクラリィへ自動追加。
  • Title / NameRegisterには追加せず、既存の SpringBone があるモデルも必ずスキップ。
  • TitleとGameで12本のチェーン定義を ClarieHairChains から共有。

軽量化と安全補正

  • 62セグメントを1コンポーネントでまとめ、固定60Hzで更新。
  • 身体コライダーとの最大約800距離判定/フレームを省略。
  • 移動93%・旋回35%を仮想先端へ継承し、残りを柔らかな遅れとして使う。
  • 最大偏角42°、0.6秒のソフトスタート、1.5m以上の瞬間移動で履歴リセット。

Ver1.4 リリース確認観点

海の光

  • Titleで現実時刻を選ぶと、端末時刻と季節に応じた見た目になる。
  • カスタム時刻を4:30 / 10:30 / 16:45 / 17:30 / 21:00 / 24:00で動かし、海と太陽が連続変化する。
  • ゲーム中ポーズでもスライダーが timeScale=0 のまま即時反映される。
  • Normal/TimeAttack/CenterHitの保存スロットが混ざらない。
  • 1.3の旧5タブ設定が対応するカスタム時刻へ1回だけ移行される。

クラゲ救助

  • クラリィが届く落下を横取りせず、確実に届かない画面内の落下だけを救う。
  • ワープの伸縮・粒子・浮上・真上へのバウンス・上方退場が一連で見える。
  • 救助が通常のスコア/SE/触覚/難易度更新を通り、吹き出しが約2秒表示される。
  • 1プレイ2回で止まり、退場後20秒は補充されない。
  • 落下寸前でも、一度引き受けた救助が途中キャンセルされない。

クラリィの髪

  • Normal / TimeAttack / CenterHitで自動追加され、TitleのSpringBoneと二重起動しない。
  • 走り出し・停止・左右旋回で、毛束が控えめに遅れて戻る。
  • 120fpsでも物理更新は固定60Hzで、フレームレートによる揺れ方の差が大きくならない。
  • 復活などの位置復元で履歴がリセットされ、髪が大きく飛ばない。
  • 全12衣装で胴体・顔への目立つ貫通がないか目視確認する。
