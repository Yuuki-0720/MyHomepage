ゲーム概要

基本体験

プレイヤーはクラリィを操作し、頭の判定エリアでシャボン玉を弾いてスコアや距離を伸ばします。 操作はシンプルですが、ヒット音、破裂音、端末振動、Bubbleのぷにょ変形、海中演出により「触って気持ちいい」反応を重ねています。

  • 頭の中心に近いほど高得点・高精度。
  • Normal / Time Attack / Center Hit の3モード。
  • 落下・時間切れ・規定ヒットでリザルトへ遷移。

作業用体験

Clock Mode / Pomodoro / Timer は、海中の美しさとクラリィのかわいい動きを活かした「眺めるゲーム」機能です。 Ver1.3では海の時間帯を実時刻や好みに合わせられるため、勉強・作業・休憩の背景としての価値が強まりました。

  • タイトルは実時刻・季節に連動する海を表示可能。
  • ゲーム中もポーズから昼/夕焼け/日没/夜へ即時切替。
  • クラゲコンパニオンが長時間滞在時の癒やし要素になる。
  • 仕様書のTitle代表画面は昼を基調にし、夕方・夜は海時間サイクルの差分として紹介。

ゲームモード

Normal Endless

Bubbleを落とすまで続く基本モード。距離、ヒット回数、命中率、スコアを伸ばす。海時間の既定は 日中。

  • スコア、総移動距離、最大/平均精度を記録。
  • 同じ位置での放置連続ヒットはコンボガードで抑制。
  • 落下/破裂でリザルトへ移行。

Time Attack

60秒でどれだけ距離とスコアを伸ばせるかを競う短時間モード。海時間の既定は 夜。

  • 時間切れまたは落下で終了。
  • テンポ重視。ランキング/シェアとの相性が高い。
  • ポーズ画面から海時間を即時変更可能。

Center Hit

15回のヘディングで中心精度を競う採点モード。海時間の既定は 夕焼け。

  • 中心ほど高得点。端でも最低命中率を保証。
  • 連続高精度でコンボ倍率が上昇。
  • Bubbleの水平移動はランダム方向で、中心狙いを成立させる。

Bubble 挙動 / 当たり判定 / Shader 詳解

Bubble は HeadingBall の物理、BubbleEffect のヒット変形、 BubbleShader の透明膜、BubbleBurst の破裂演出で構成されます。 Ver1.3でも中核ロジックは維持されています。

通常モードの跳ね返り

  1. Bubble が HeadingZone に衝突する。
  2. 頭ローカル座標へ変換し、中心からの offset を求める。
  3. centerThreshold 内は真上、外側は衝突方向へ Slerp して角度を付ける。
  4. targetHeightY と滞空倍率から垂直初速・カスタム重力を計算。
  5. 水平速度を更新し、Bubble の linearVelocity へ反映。

放置コンボ防止

Normal / TimeAttack では、前回とほぼ同じ頭ローカル位置で連続ヒットした場合に comboGuardDistance と comboGuardMaxRepeats で放置判定します。 閾値を超えると命中率を0にし、ランダム水平ナッジでループを崩します。

Center Hit は毎回ランダム方向へ飛ばすため、同じ位置での放置ループが成立しにくい設計です。

シャボン玉 Shader

透明膜とFresnel

BaseColor、Alpha、Fresnel を組み合わせ、外縁ほど光る薄膜感を作ります。 命中方向の色は MaterialPropertyBlock 経由で個体へ反映し、共有Materialを汚さない設計です。

ぷにょ変形

BubbleEffect.TriggerHitSquish(finalDir) が衝突方向を渡し、 _SquishProgress を減衰振動として更新します。 Shader は _HitDirection 軸を縮め、直交方向を膨らませます。

Shader/Material パラメータ役割
_BaseColorBubble本体の薄い色。ヒット色と元色をブレンドする。
_FresnelColor外縁の発光色。命中方向・反応の気持ちよさを視覚化。
_SquishProgressヒット直後の変形量。時間経過で0へ戻る。
_HitDirectionどの方向へ潰すか。物理反射方向に対応。
_Surface / _SrcBlend / _DstBlendURPの透明描画/アルファブレンド。パーティクルやクラゲMaterialでも手動設定が必要な箇所あり。

Ver1.3 クラゲコンパニオン

クラゲコンパニオンは、クラリィやプレイヤーの周囲を長時間ふわふわ漂う癒やし要素です。 タイトルでは経過時間で増え、ゲームでは距離連動に切り替えられる構造になっています。

生成ルール

時間スケジュール15, 45, 180, 600秒。タイトルでは15秒で1匹、45秒で2匹、3分で3匹、10分で4匹。
距離連動15, 40, 80, 140m。"Bubble"タグの HeadingBall.TotalTravelDistance を読む。
同時生成SPAWN_STAGGER 0.6秒 で1匹ずつ。スロット数と maxCompanions で上限。
ターゲットTitleClarieController → PlayerController の順に自動検出。Explicit指定も可能。

配置スロット

中心は target.position + (0, 0.6, 0)。既定はクラリィ周囲4点です。Sceneビューでは選択時ギズモで番号付きの球が表示されます。

#1(-0.80, -0.50, -0.30) 左下
#2(0.85, 0.70, -0.30) 右上
#3(0.95, 0.00, -0.20) 右
#4(-0.85, 0.60, -0.30) 左上

1匹の状態遷移

Idle→ Approaching
画面外から一定速度→ Attached
SmoothDampで追従→ Leaving
上方へフェード

動きのロジック

  • 接近は Vector3.MoveTowards による一定速度。到着時に急に詰める不自然さを防ぐ。
  • 追従は Vector3.SmoothDamp。MAX_SMOOTH_DT 0.05 と1フレーム移動上限でワープを防止。
  • スロット内で wanderRadius とsin波を使い、固定点ではなく持ち場の中で漂わせる。
  • minDistanceFromCenter 0.85 でクラリィに近づきすぎない。

アニメとマテリアル

  • jellyfish_animated.fbx + Jellyfish.controller でFBXのベル収縮アニメをループ。
  • Animator+Controllerを検出した場合、コード側の拍動/上下浮遊/傾きは自動OFF。
  • Jellyfish.mat はURP/Lit Transparent、BaseColorは白寄り水色、Alpha 0.45。
  • フェードは MaterialPropertyBlock で _BaseColor.a を個体ごとに更新。

貝がら通貨 / 衣装コレクション

魚図鑑と同じ海のコレクションとして、10種の貝がらを用意しています。貝がらはクラリィの衣装と交換するゲーム内通貨です。 Normal Endlessではフィールドで拾い、Time AttackとCenter Hitではプレイへの集中を優先してリザルト報酬として獲得します。

モードフィールド貝がら獲得条件報酬リザルト表示
Normal Endless表示（同時5個）Playing中に接近して拾得貝がらごとの value（現行は1）貝がらアイコン + 「拾った貝がら +N」
Time Attack非表示60秒を完走3 + floor(ヒット数 / 10)、最大8貝がらアイコン + 「獲得した貝がら +N」
Center Hit非表示15回のヘディングをクリア6 + floor(最終スコア / 100,000)、最大10貝がらアイコン + 「クリア報酬 +N」

Normalの貝がらはプレイ開始時、または自分で拾った貝がらの20〜35秒後の再出現時だけに現れます。 未取得の貝がらをプレイヤー移動に合わせて再配置しないため、理由のない突然出現を防ぎます。

PlayFab送信の扱い

  • ゲームオーバー時にモード別のStatisticを更新。
  • 複数Statisticは1回の UpdatePlayerStatistics にまとめて送信。
  • 未ログイン時は送信待ちキューへ保持し、ログイン後にまとめて送信。
  • ランキング画面は GetLeaderboardAroundPlayer で自分周辺を取得。

フォールバック

PlayFab未ログイン、開発者モード、SDK未定義時は、同じStatistic名に対応する PlayerPrefs のローカルベストを表示します。オンライン値とローカル値を混同しないよう、ランキング画面ではローカルフォールバックとして扱います。

Ver1.3 リリース確認観点

海時間

  • TitleでReal選択時、端末時刻に応じた見た目になる。
  • 設定タブでDay/Gold/Sunset/Nightへ切り替わり、保存後も維持される。
  • ゲーム中ポーズで海時間を切り替え、timeScale=0でも即時反映される。
  • Normal/TimeAttack/CenterHitの保存スロットが混ざらない。

クラゲ

  • Companion Prefabが各シーンで設定済み。
  • タイトル滞在15秒以降に画面外から自然に登場する。
  • Animator付きFBXではコード拍動がOFFになり、二重アニメにならない。
  • シーン遷移時にターゲット消失で自滅し、不要な残骸が残らない。
